# Портфолио Тимура

Статический сайт о разработке сайтов и цифровых решениях. Контакт: https://t.me/godhamm.

## Работы и концепции

- **Х.А.Н** — единственный здесь опубликованный проект: https://khan-ufa.ru.
- **Концепции работ:** Athletic Aquamarin, «Лезвие», KALIBR.

В разделе работ четыре карточки: один опубликованный сайт и три концепции. У каждого есть просмотр для компьютера и телефона. Неподтверждённые кейсы ботов, приложений и изображения из Kwork удалены. Два портрета в кардиганах созданы по фотографиям пользователя.

## Локальный просмотр

```sh
python3 -m http.server 8000
```

Открыть `http://localhost:8000`. Сайт без сборки и внешних зависимостей, кроме необязательной загрузки шрифта DM Sans (есть системный запасной шрифт).

# Портфолио Тимура

Статический сайт о сайтах, Telegram-сценариях и мобильных интерфейсах. Контакт: https://t.me/godhamm.

## Работы и концепции

- **Х.А.Н** — единственный здесь опубликованный проект: https://khan-ufa.ru.
- **Сайты, концепции:** Athletic Aquamarin, «Лезвие», KALIBR, студия интерьеров, «Лесные домики», «Уютный Дом».
- **Telegram, концепции:** мини-приложение для записи, бот для записи, бот для заказов.
- **Мобильные интерфейсы, концепции:** FORMA (три экрана), «Дела в порядке», доставка продуктов, заказ в кафе, автосервис, фитнес-студия.

Всего 16 карточек: один опубликованный сайт и 15 демонстрационных концепций. Концепции не выдаются за клиентские проекты, работающих ботов или приложения в магазинах. Часть иллюстраций создана по запросам владельца для демонстрации интерфейсов. Два портрета в кардиганах созданы по фотографиям пользователя.

## Локальный просмотр

```sh
python3 -m http.server 8000
```

Открыть `http://localhost:8000`. Сайт без сборки и внешних зависимостей, кроме необязательной загрузки шрифта DM Sans (есть системный запасной шрифт).

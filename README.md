# Портфолио Тимура

Статический сайт для услуг и цифровых продуктов.

## Проекты

- Х.А.Н — опубликованный сайт: https://khan-ufa.ru
- Athletic Aquamarin — концепция сайта с отдельным разбором.
- Запись в студию — визуальная концепция Telegram Mini App.
- Бот для записи — демонстрационный сценарий Telegram-бота.
- FORMA — концепция интерфейса iOS, приложение не опубликовано.
- «Дела в порядке» — демонстрационный экран Android, приложение не опубликовано.

Контакт: https://t.me/godhamm

Все изображения лежат в `assets/`. Два портрета в кардиганах созданы по фотографиям пользователя и служат иллюстрациями. Не представлять концепции как оплаченные клиентские проекты или работающие приложения.

Локально: `python3 -m http.server 8000`, затем `http://localhost:8000`.

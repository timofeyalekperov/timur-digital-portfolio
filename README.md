# Портфолио Тимура Алекперова

Статический сайт о разработке сайтов и цифровых решениях. Контакт: https://t.me/AlekperovWork.

## Работы и концепции

- **Х.А.Н** — единственный здесь опубликованный проект: https://khan-ufa.ru.
- **Концепции работ:** Athletic Aquamarin, «Лезвие», KALIBR.

В разделе сайтов четыре карточки: один опубликованный сайт и три концепции. У каждого есть просмотр для компьютера и телефона. Отдельно показаны интерактивные прототипы Telegram-бота, Telegram Mini App, iOS (FORMA) и Android. Они обозначены как концепции, а не как клиентские запуски. Баннеры из Kwork не используются. Текст в блоке отзыва вымышленный и прямо подписан как пример, а не клиентский отзыв. Два портрета в кардиганах созданы по фотографиям пользователя.

## Локальный просмотр

```sh
python3 -m http.server 8000
```

Открыть `http://localhost:8000`. Сайт без сборки и внешних зависимостей, кроме необязательной загрузки шрифта DM Sans (есть системный запасной шрифт).
